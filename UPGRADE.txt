Night Vision - Configurable 1.0: updating from 0.1.x

Close the game, install the new Night-Vision-Configurable.zip through Vortex as
an update to the existing mod, and deploy. You do not need to disable or remove
the previous version manually, or change the mod type yourself.

With one profile, Vortex normally replaces the older version automatically.
With multiple profiles, choose Update current profile or Update all profiles.
Both run the new archive's installer. It selects Root (game folder), puts the
scripts at their existing location, and adds the new visual assets.

On your next launch, the included settings migration adds missing controls,
converts the old brightness setting, and preserves existing choices. Black &
White values between 5% steps are rounded to the nearest step, with the original
assignment retained as a comment. A settings.ini.before-upgrade backup is saved
before changing an older INI; an existing backup is kept.

The archive does not include or overwrite your personal settings.ini. Normally
this game-created file stays in place during Vortex replacement and is migrated
automatically. A separate preference backup is optional protection, especially
if you previously added that INI to Vortex's managed files or staging folder.

Invalid or duplicate settings are left untouched; correct the reported entry
before retrying. Older brightness settings may need an adjustment because the
appearance has changed.

Simply clicking Deploy without installing the new ZIP does not update the mod.
If the older installation already had incorrect routing, reinstall through
Vortex to rerun its installer. Do not enable both versions in the same profile.
