# Changelog

## 0.1.1

- Night vision stays on until you turn it off or become human. Loading a save or camera changes no longer turn it off.
- Fixed other visual effects interrupting night vision.

## 0.1.0

- Added vampire night vision on keyboard N and a 0.6-second left-stick hold.
- Added a 0–100% natural-colour to monochrome slider in 5% steps and independent brightness adjustment.
- Added live Mod Settings integration, an optional controller shortcut and Logging.
- Restores owned camera settings when vision stops or the player context changes.
